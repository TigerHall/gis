# 一个 GIS 自学者的五年路线图

有人问我：GIS 到底该怎么自学？我想了想，这五年我大概走过三条路：**看图、读数据、写代码**。

## 第一年：先会“看”

别急着写代码。先把地图看懂：

- 投影是什么？为什么 Greenland 看起来比非洲还大？
- 比例尺、经纬网、图例怎么读？
- 打开 Google Earth，把自家城市从太空看到街道。

> 看不懂地图的人，写出来的代码也只是把错的东西画得更漂亮。

## 第二年：读懂“数据”

地图背后是数据。这一年我啃下了：

- **GeoJSON / Shapefile / GeoPackage** 的区别与互转；
- 坐标系：WGS84、GCJ-02（火星坐标）、BD-09 的纠偏；
- 用 QGIS 做缓冲区分析、叠加分析。

工具上，QGIS 是免费的救命稻草，PostGIS 让我第一次知道“空间查询”能有多爽：

```sql
SELECT name FROM cities
WHERE ST_DWithin(
  geom,
  ST_SetSRID(ST_MakePoint(104.07, 30.66), 4326),
  0.5
);
```

## 第三年：开始“写”

前端地图库是分水岭。我从 Leaflet 入门，后来碰到了反子午线、聚类卡顿、底图选型这些真问题（前面几篇都写过）。

这一年我还补了：

- JavaScript / TypeScript 基础；
- 一点点 WebGL（为了上万点不卡）；
- 用 Canvas 插件把点渲染从 DOM 搬到画布。

## 第四、五年：搭系统

现在我能独立搭一套带**搜索、聚类、多底图切换、标签分类**的 Web GIS。回头看，最重要的不是某个 API，而是：

1. 遇到坑先想“这是数据问题还是渲染问题”；
2. 把可复用的逻辑沉淀成笔记与代码片段；
3. 写文档——半年后你就是那个“别人”。

## 给后来的你

如果你也在自学，记住：GIS 不神秘，它只是**地理 + 数据 + 代码**三件事的交集。哪块弱，就补哪块，别等“全学会了再动手”。
