关于「地脉」

一个地理科学 / GIS 爱好者的边学边写之地。

这里写什么

地图、数据、代码的交集。从怎么用 Leaflet 搭一张地图，到 GeoJSON、WMS、反子午线这些绕不开的坑， 再到我自己这些年学 GIS 的路线图。文章全部用 Markdown 书写，支持代码高亮。

关于我

  • 坐标相关方向的自学者，常年和投影参数、瓦片、坐标系打交道；
  • 喜欢把踩过的坑写成笔记，半年后自己还能看懂；
  • 相信“看懂地图 → 读懂数据 → 动手写代码”这条路径。

技术栈

  • 静态站点：纯 HTML / CSS / JavaScript，零构建、零依赖后端；
  • Markdown 渲染：marked + DOMPurify + highlight.js（均已本地化）；
  • 可部署到任意静态托管（GitHub Pages / 对象存储 / Nginx）。
