# 数据图层使用说明

本面板加载的是预置的矢量数据图层（GeoJSON 格式），所有数据已存储在服务器端，无需用户上传即可使用。

> ℹ️ 本文件与 `assets/geo-config.js` 第 ③ 段的图层清单**一一对应**：
> 面板里看到什么，这里就写什么。改完图层清单请顺手同步本文件。

## 基本使用

- **勾选/取消**：点击图层名称前的复选框可切换图层显示
- **全选/全不选**：点击图层组标题行右侧的复选框可批量操作
- **折叠/展开**：点击图层组标题可折叠或展开该组
- **缩放至范围**：在左侧图层面板底部点击 🔍 按钮可定位到该图层范围
- **图层设置**：点击图层行右侧的 ⚙️ 可单独调整该图层的颜色模式、颜色、透明度、图标、标签字段等
- **下载 GeoJSON**：图层加载完成后，点击其左侧的绿色状态圆点可下载该图层的原始 GeoJSON 数据（高级功能，需激活后可用）

## 图层切换

勾选后，地图会自动缩放到该图层的范围。取消勾选后，图层从地图中移除，再次勾选会恢复显示并使用之前设定的样式模式。

## 支持的样式模式

- **单色**：所有要素同一颜色
- **逐项**：每个要素按顺序分配不同颜色
- **字段**：根据要素属性中的数值字段渲染渐变颜色

## 支持的数据来源

### 全球板块构造

- **全球16大板块 plate16** — USGS 板块边界数据
- **全球280个板块 (Hasterok2022)** — Hasterok et al., 2022 新一代板块构造模型
- **大陆板块 / 大洋板块** — 大陆与大洋板块分类
- **洋中脊和转换断层 MOR&TF** — 全球洋中脊及转换断层（默认红色）
- **海沟 Trench** — 全球海沟分布
- **其他板块边界 Other boundries** — 板块边界补充数据
- **大西洋 / 印度洋 / 太平洋断裂带** — 三大洋断裂带分区数据

### 洋中脊作用域

- **1全球洋壳 GlobalOceanicCrust** — 全球洋壳范围
- **2大洋域 OceanDomian / 3次大洋域 SubOceanDomain** — 大洋域分级
- **4洋中脊作用域 RidgeDomain** — 洋中脊作用域范围
- **全球陆壳 GlobalContinentalCrust** — 全球陆壳范围

### 海底基础信息

- **火山 volcanos** — 全球火山分布（三角图标，标注字段 `NAME`）
- **4.5级以上地震(2024-2026)** — 近年中强地震
- **7.0级 / 8.0级以上地震(1800-2023)** — 历史大震目录
- **热点 hotspots** — 全球热点位置（同心圆图标，标注字段 `geodesc`）
- **大火成岩省 (Johansson)** — Johansson et al. 大火成岩省数据
- **洋壳年龄30Ma间隔** — 海底年龄等时线
- **海底地名点 / 多点 / 线 / 面 Gazetteer_*** — 海底地名系列（标注字段 `name`，已加入默认搜索）

### 海洋地理信息

以「人在海上活动的痕迹与区划」为主 —— 海运、海域区划、安全事件、通信。

- **全球海盗事件 ASAM Piracy Events** — 按事件敌对程度字段着色
- **海底光缆 Submarine Cables** — TeleGeography 海底光缆
- **光缆登陆点 Landing Points** — TeleGeography 光缆登陆点
- **海区 geography_marine_polys** — Natural Earth（naturalearthdata.com），标注字段 `name_zh`，已加入默认搜索
- **港口 ports** — Natural Earth（naturalearthdata.com），标注字段 `name`，已加入默认搜索

### 大型异常区

- **LLSVP** — 大型低剪切速度区
- **Dupal异常洋 DupalOcean** — Dupal 异常区范围

### 海底矿产资源

- **热液喷口 HydrothermalVents(ISA)** — 国际海底管理局热液喷口数据
- **多金属结核 Fe-MnNodule(NOAA) / 富钴结壳 Co-richCrust(NOAA)** — NOAA 数据
- **PMN 全球多金属结核勘探合同区 / PMS 多金属硫化物勘探合同区 / CFC 富钴结壳勘探合同区** — ISA 勘探合同区（按承包商字段着色）
- **EBSA 海洋保护区&特殊生态区** — 具有生态或生物重要性的海域

### 地质站位

- **DSDP / ODP / IODP03-13 / IODP13-26** — 深海钻探计划站点数据
- **NWIR_rock / SWIR_rock / SEIR_rock / SEIR_offaxis_rock** — 洋中脊岩石采样
- **RedSea_rock** — 红海裂谷岩石数据

### 陆地地理信息

以陆地国家 / 行政区与陆域地质为主体（海洋相关内容见「海洋地理信息」组）。

- **世界各国** — 全球 195 个国家和地区
- **富裕国家** — 人均 GDP 超过 5 万美元的国家
- **贫穷国家** — 人均 GDP 低于 5000 美元的国家
- **人口大国** — 人口超过 1 亿的国家
- **经济强国** — GDP 超过 1 万亿美元的国家
- **领土大国** — 领土面积超过 100 万 km² 的国家
- **全球军事设施 Overseas Military Bases** — 海外军事基地
- **中国县城名称 China County** — 标注字段 `NAME`，已加入默认搜索
- **浙江适飞区(2026-05-12)** — 浙江省交通运输厅 2026-05-12《关于公布新版浙江省无人驾驶航空器适飞空域范围的公告》
- **盆地 (Evenick2021)** — Evenick, 2021 全球沉积盆地数据
  - 沉积盆地地理上属陆地，故归入本组（2026-09-17 从「海底基础信息」移入）
  - CGG 全球沉积盆地数据集体积过大（10 MB gz），已并入 Evenick2021，不再单独开放

### 测试数据

- **PIC 45万点** — 性能测试用 45 万点矢量数据集（整组默认隐藏，不对公众开放）

## 维护提示（改代码时看这里）

本文件是 `assets/geo-config.js` 第 ③ 段 `window.geoJsonGroups` 的**文字镜像**。

- 增删图层、改图层名、**把图层在组之间挪动**之后，都要回来同步本文件
- 面板只渲染「非 hidden」的组与图层，所以这里**只写实际能看到的**；
  隐藏项统一放到上面「暂未开放」一节
- 想核对清单是否一致，可以直接跑：`node .workbuddy/artifacts/dump-layers.js`
  （按组打印全部图层及其 `labelField / color / icon / colorMode / hidden` 等字段）
