# 本地图层查看使用说明

本面板用于加载您自己的矢量数据文件或使用投点功能在地图上创建点位。**所有数据仅在本机浏览器中解析加载，不会上传至任何服务器。**

## 基本使用

- **勾选/取消**：点击图层名称前的复选框可切换图层显示
- **全选/全不选**：点击面板标题行右侧的复选框可批量操作
- **折叠/展开**：点击面板标题可折叠或展开

## 上传矢量文件

支持通过以下两种方式加载本地矢量文件：

### 方式一：按钮上传

点击面板底部的 **「📄 上传矢量（单文件）」** 按钮，在弹出的文件选择器中选中文件即可。

支持的格式：

- **GeoJSON**（`.geojson` / `.json`）
- **KML**（`.kml`）
- **KMZ**（`.kmz`，压缩的 KML）
- **ZIP 压缩包**（`.zip`，可内含 SHP / KML / GeoJSON）

### 方式二：拖拽文件

直接将矢量文件或文件夹从文件管理器拖拽到页面中，即可自动识别并加载。

支持拖入的格式同上（GeoJSON、KML、KMZ、ZIP）。

### PWA 安装后直接打开（推荐）

本站为 **渐进式 Web 应用（PWA）**，安装到桌面后，可以直接在文件管理器中选中矢量文件，使用「打开方式」选择本站来加载文件：

1. 将本站添加到桌面（浏览器地址栏右侧的安装图标）
2. 在文件管理器中右键矢量文件 → **「打开方式」** → 选择本站
3. 文件会自动加载到地图上

这种方式最为便捷，无需先打开页面再拖拽或选择文件。

## 投点功能

面板内置**投点编辑器**，可在地图上手动添加点位：

- 点击 **「投点编辑」** 按钮展开编辑器
- 支持两种方式添加点坐标：
  - **表格编辑**：直接输入经纬度（纬度在前或经度在前均可）
  - **批量粘贴**：粘贴多行坐标数据，自动解析
  - **地图点击**：点击地图上的位置自动填写坐标
- 可批量导入坐标后一键生成点图层
- 投点数据可通过表格导出

## 数据安全说明

- 所有上传文件**仅在浏览器本地内存中解析**
- 不会将文件数据传输到任何外部服务器
- 刷新页面后本地图层会清除（可通过再次拖入或上传恢复）
