## 5 出图点要素：大小/聚类与屏幕对齐（真 Bug）

三个根因（见 MEMORY.md §3 新增条目）：

1. `describeMarker` 只认 `<svg>/<img>` → `.station-dot`（`createLabeledMarker` 的圆点）
   匹配不上 → 掉进「半径 3px 红点」兜底，而屏幕是 20px。→ 新增 `kind:"dot"`。
2. 只遍历 `L.Marker` 图层对象 → `WorldCopyGroup` / `markerClusterGroup` 里的点收不到
   （`map.eachLayer` 不递归）。→ 改成扫 `markerPane` 里的 `.leaflet-marker-icon`：
   量矩形中心反投影成 latlng、按 `svg/img`/`.station-dot`/`.marker-cluster` 三分支描述、
   按 `innerHTML+尺寸` 缓存序列化结果（3000 点也不至于分钟级）。
3. Canvas 点层自套一套规则（iconSize 铺满正方形、兜底 `iconSize/2`、永不聚类）。
   → **直接复用 `layer._lastClusters`**（MarkersCanvas 每次 `_redraw` 存下的屏幕绘制单元，
   x/y 是容器 CSS px，含聚类结果），出图只做 `×posK`；没有则本地按同算法兜底
   （视口内聚类 + 半径照抄 `10+log2(n)*5 clamp 36`）。

验收（1261×841、火山 DOM 点 + 海底地名 Canvas 点同框、posK≈1）：出图与屏幕的红三角/气泡
**位置、尺寸、计数逐个对上**（`.workbuddy/artifacts/cmp-points2.png`）；
`report.frame` 与 `map.getBounds()` 差 < 0.01°。

## 8 坑（新增）

- **placeholder 会撑高 textarea**：空态高度别只信 CSS `min-height`，量一次 scrollHeight。
- **`map.eachLayer` 不递归**：点在组/世界副本/聚类里必须走 DOM 或 `getAllChildMarkers`。
- **聚类不要自己重算**：屏幕已经算过的 `_lastClusters` 拿来用，比"同算法再算一遍"可靠
  （网格原点差几十像素就能让气泡分组全变）。
- 字段名大小写：模型给的 `fields/where.field` 必须映射回数据真实键名。

## 9 输入框改成浮层（同日二改，用户口径）

> 「输入框整体做成一个悬浮在对话框上面的，不需要单独再有框线，但是要确保对话能全部展示出来」

- `.ogv-ai-comp` → `position:absolute; left/right/bottom:0; z-index:4`，**去掉 `border-top` 分割线**，
  顶部 76%→100% 渐变到 transparent（先给 `background: var(--c-bg)` 兜底，再覆盖渐变，
  避免老浏览器不认 `color-mix` 时整条声明作废、浮层变全透明）；渐变区 `pointer-events:none`，
  只有子元素接指针 —— 用户还能在那一段滚动消息。
- `.ogv-ai-box` 静止态 `border:1px solid transparent` + `background: var(--c-bg-alt)` + 投影
  （深色主题投影加重到 0.55，否则 #181818 与 #111 糊成一片）；focus/录音才出现彩色描边。
  `border` 保留 1px 是为了换色时不出 1px 位移。
- 脱流后消息区不再自动让位 → 新增 `_syncComposerPad()`：`padding-bottom = 浮层 offsetHeight + 10`，
  由 `ResizeObserver`（`_observeComposer()`，在 `_ensure` 里挂一次）+ `_autoGrowInput()` + `open()` 触发。
  实测：桌面浮层 104→留白 114；输入 7 行浮层 212→留白 222；窄屏 100→110 / 164→174；
  最后一条与浮层顶始终 gap≈10px，`lastFullyVisible=true`。
- `_autoGrowInput` 的上限改读 `getComputedStyle(ta).maxHeight`（CSS 媒体查询 ≤520px 时 104px），
  JS 常量只作兜底 —— 写死 148 会出现「内容超了但 `.is-max` 没打开 → 看着字被切掉却滚不动」。
- 版本 `CACHE_NAME` → v3.9.3（3.9.2 已随上一轮改动发布过一次，再 bump 一次确保拿到新文件）。
