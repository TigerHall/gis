# 2026-07-05 工作日志

## 修复横屏模式地图卡死极北坐标的BUG

**问题**：直接在横屏打开网页，地图定位到极北（约 89.8°N），且因 `maxBoundsViscosity: 1.0` 拖不回来。

**根因**：
- `index.html` 中 `maxBounds: [[-89.8, -Infinity], [89.8, Infinity]]` 的纬度 89.8° 已超出 Web Mercator 投影实际极限（~85.05°），且 `maxBoundsViscosity: 1.0` 导致一旦到达该边界就完全卡死
- `pagehide` 事件持久化坏坐标到 localStorage，`restoreMapCenter()` 恢复时无校验

**修改**：
1. `index.html:343-347` — 移除 `maxBounds` 和 `maxBoundsViscosity`，后改为 `maxBounds: [[-85, -Infinity], [85, Infinity]], maxBoundsViscosity: 0.6`
2. `geojsonloader.js:4409` — `restoreMapCenter()` 增加 `state.lat >= -85 && state.lat <= 85` 纬度校验
3. `geojsonloader.js:4420` — `initGeoJsonLayer()` 启动时自动清理 localStorage 中纬度越界的 `dupal_map_state`
4. `app.js:197` — `fetch("service-worker.js")` 改为 `fetch("service-worker.js?" + Date.now())` 防缓存，修复 PWA 更新版号后侧边栏版本号不刷新的 BUG
