## 2026-07-25

### 导出图片终版 — 系统屏幕截图 API

**最终方案**：放弃 html-to-image（DOM 截图对 Leaflet tiles + 跨域有根本性限制），改用浏览器原生 `navigator.mediaDevices.getDisplayMedia()` 系统屏幕截图。

**降级方案**：iOS/不支持 `getDisplayMedia` 的平台 — 隐藏 UI → 显示系统截图指引 toast → 用户自行截图 → 移动/缩放地图恢复 UI

**代码结构**：`restoreUI()` 统一处理三种恢复路径（成功/失败/取消/iOS 降级），`map.off("movestart zoomstart", restoreUI)` 避免重复监听

**流程**：

1. 隐藏侧边栏等 UI
2. 等两帧
3. 提示用户「请在弹出对话框中选择当前标签页」
4. 调用 `getDisplayMedia({preferCurrentTab: true})` — 浏览器弹出共享选择器
5. 获取视频帧 → 按 `mapEl.getBoundingClientRect()` 裁剪到地图区域
6. 考虑 `devicePixelRatio` 缩放后输出高清 PNG
7. 停止视频流，恢复 UI

**之前的尝试全部失败原因**：

- html-to-image 用 SVG foreignObject 序列化 DOM → 内部 `<img>` 需要浏览器重新加载 → 跨域/CORS 导致加载失败 → 全白/部分白
- 摊平 transform → 浏览器布局时序和截图时序不一致 → 瓦片位置偏移重复
- `useCORS` → 天地图部分瓦片服务器不支持 CORS 重加载
- `onclone` → 克隆文档中图片不触发加载
- **这些是 DOM 截图方案的固有缺陷，无法彻底修复**

**优势**：截取屏幕实际像素→ 零 transform/CORS/加载问题，100% 所见即所得
**代价**：首次使用需在浏览器弹窗中选择「当前标签页」确认（后续同一会话会记住）
