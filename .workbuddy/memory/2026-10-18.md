# 2026-10-18

## 第七轮：PWA 安装进入操作选项 + 状态与开关同源（v3.8.0）

用户：「PWA 安装也放进操作选项里…如果没安装 PWA，则每次进入后弹窗提示，操作选项开关和
PWA 安装状态同步，和鼠标控件一样能显示状态，他们可以用同一套逻辑」。

1. **「操作 → 安装到桌面」= 标准开关项**（复用「鼠标坐标」那套 `TOGGLE_GROUPS` + `toggleConfig`）
   - label/icon/`state:true`（渲染状态徽标），放在「操作」组首位。
   - `initToggle` 新增 `cfg.truth()` / `cfg.syncStatus(on)`：状态由外部事实决定时跳过 `getBool`，
     存储只写镜像。→ 这是**新能力**，以后同类"只读状态"开关可复用。
   - `syncStatus`：已装 → `cb.disabled=true` + `.is-locked` + 徽标「已安装」（绿）；
     未装 → 可拨 + 徽标「未安装」（灰）。
   - `enable(userInitiated)`：`!userInitiated` 直接 return（恢复绝不能再装一次）；否则 `OGVInstall.install()`。
   - `disable`：浏览器没有卸载 API → 按真值回弹 + toast 指引「用浏览器菜单卸载」。
   - `SYNC_BLOCK` 加 `pwaInstallToggle`（安装状态是本浏览器的事实，别的标签页的镜像值不能指挥本页）。

2. **pwa-install.js 改造**
   - `isInstalled()` 成为唯一真值（standalone / appinstalled / installedAt / getInstalledRelatedApps）。
   - `onChange(fn)` 广播 + `_emit()`：装好 / 取消 / 改 neverAsk 都通知面板重算。
   - 「以后再说」/✕/Esc → `_dismissedThisPage`（**只压本次页面**，内存变量）；删掉 14 天冷却。
     「不再提示」= `neverAsk` 永久，`show()` 里硬门槛，但**新增的 `install()` 不受限制**。
   - 新增 API：`install()` / `isInstalled()` / `canPrompt()` / `onChange()` / `setNeverAsk()` / `neverAsk()`。
   - `_probeRelated()`：`navigator.getInstalledRelatedApps()` 兜底识别"早在我们有这段代码前就装过、
     且这次从地址栏进来"的老用户。
   - 修 bug：`_showSteps()` 里先改主按钮 `data-pwa` 再查 `[data-pwa="later"]` → 抓到的是刚改过的
     自己 → 「知道了」被 `display:none` 吃掉。**必须先藏原来的 later**。

3. **AI 读名字**：`_optionItems` 新增 `_labelText()`（clone 后剔除 `.toggle-state`），
   否则模型看到「安装到桌面未安装」，`set_option` 回填对不上。

4. **顺手加固两处会连带整片开关失灵的偶发崩溃**
   - `legendToggle.enable`：`L.control.legend` 未加载 → 抛错 → `initToggle` 串行循环中断 → 后面开关全不初始化。已判空 + 回退开关。
   - `geomenToggle.disable`：`map.pm` 不存在时 `map.pm.removeControls()` 抛错，同上。已判空。

5. **实测**（Playwright + 真浏览器）
   - 首次进入 5.98s 自动弹；点「以后再说」→ 刷新 6.24s **又弹**（证明只压本次）。
   - 点「不再提示」→ 刷新 9s 内不弹。
   - `dispatchEvent(new Event("appinstalled"))` → 开关 `checked:true, disabled:true, 徽标「已安装」`，组徽标 0/1→1/1。
   - 真拨开关（无 prompt 事件）→ 卡片出图文步骤、「知道了」可见 / 原「以后再说」隐藏、**开关回弹 false**。
   - `neverAsk=true` 时 `install()` 仍能弹卡片（不是"禁止安装"）。
   - AI `_optionItems` → `{name:"安装到桌面", group:"操作"}`（无状态文字）。
   - `errors: []`（连跑两次；仅首次 SW 安装时有 5 条 `OGVStorage` undefined 的竞态，与本轮无关）。

6. SW `CACHE_NAME → v3.8.0`；CHANGELOG 写 v3.8.0。

## 测试工具坑（本轮新增）
- **侧栏「设置」是 `#toggleSection` 这个外层 `<details>`**，收起时内容用 `max-height:0` 裁剪 →
  子元素 `getBoundingClientRect()` **仍有尺寸**，但 element screenshot 报 "not visible"、clip 截到空白。
  必须先 `document.getElementById("toggleSection").open = true`。
- `page.screenshot({clip})` 用的是**文档坐标**；元素在内部滚动容器里滚动后要对齐视口坐标，
  否则截到的是别处。稳妥做法：`sc.scrollTop = sc.scrollHeight` → 读 rect → `sc.scrollTop += rect.top - 330`。
- `#panelScroll` 是**数据图层**的滚动容器，不是整个侧栏；设置项也在里面，但顺序靠前。
