### 踩到的坑（已写进 MEMORY.md §6）

1. **Geoman 画圆 = 点一下定圆心 → 再点一下定半径**，不是按住拖。
   实时读数不能自己记 `mousedown` 的圆心（两次点击中间夹的 `mouseup` 会把它清掉），
   要读 `Draw.Circle._layer/_centerMarker/_layerGroup`。
2. **`L.Circle = L.CircleMarker.extend({...})`**（`leaflet.js: gi=fi.extend`）。
   判「地理圆 vs 像素圆」只能 `instanceof L.Circle`；
   第一版写 `&& !(x instanceof L.CircleMarker)` 恒 false → 所有圆都被当像素圆
   （弹窗显示「272060 px」，输入 300 km 圆纹丝不动）。
   **这个 bug 是被测试顺带抓到的** —— 我原以为只是测试写错了。
3. **Geoman 默认 `finishOnEnter:false` / `exitModeOnEscape:false`**（本 build 实测）
   → 纯键盘无法收尾（WCAG 2.1.1 A 级）。已用 `map.pm.setGlobalOptions()` 打开；
   注意 `addControls()` **不吃**这两个键。
4. `page.evaluate` 的函数体里**内嵌 helper 必须在同一函数体内声明**，否则
   `ReferenceError: glyph0 is not defined`（我第一版回归脚本就这么挂的）。
5. minified 单行文件 grep 不出来 → 用 `node -e` 截 `s.slice(indexOf(k), +500)` 读源码，
   比反复猜快得多（`_handleEnterKey` / `finishOnEnter` / `gi=fi.extend` 都是这么定的）。

## v3.0.6 — 修「测量时点击仍被属性悬浮窗吃掉」（用户复测反馈）

用户复测：「确实能吸附了，但是点击下去后，优先触发的还是悬浮窗，导致点击不了设置点。」

v3.0.5 的屏蔽**只写了一半**，两条真实泄漏路径都没堵住：

### 泄漏一：`pointer-events` 可继承，但元素自身声明优先

v3.0.5 只把 `none` 加在 **pane** 上。这对点要素管用（marker 图标自身无声明，老实继承），
但线/面要素带了 `.leaflet-interactive` / `.hit-area`，而

- `leaflet.css`：`path.leaflet-interactive { pointer-events: auto }`
- 本项目：`path.hit-area { pointer-events: stroke !important }`

都是**元素自己**的声明 → 父级 `!important` 改变不了子元素自身声明的计算值。
**探针实测非绘制态这 528 条路径的 PE 就是 `stroke`**，绘制态才变 `none`。

修法：选择器改为 pane + `svg`/`path`/`img`/`.leaflet-interactive`/`.hit-area` 全覆盖，
并全部带 `!important`（否则压不过 `path.hit-area`）。

### 泄漏二：Canvas 路径自己监听 map 事件，CSS 根本拦不到

`Leaflet.MarkersCanvas.js` `onAdd` 里挂了 `map.on("click", this._fire)` 与
`map.on("mousemove", this._fire)`，自己用 RBush 做命中检测。
CSS 只是让点击**穿透**到 `.leaflet-container`（Geoman 正需要这个），
而 `map` 的 click 照样触发 → `onFeatureClick` → 弹属性窗；
命中聚合簇还会 `map.setView()` 跳级缩放；`mousemove` 会把光标改成 pointer。

修法：`_fire` 开头用 `OGVMeasureTools.isDrawing()` 加闸（同时复位光标）。

### 验证

- 新增探针 `.workbuddy/artifacts/probe-fix-clickthrough.js`：**用合成 Canvas 图层**
  （`L.markersCanvas` + 40 个假要素）精确验闸，比加载几万点真实图层更确定 → **10/10**。
- `verify-5req.js` 全量回归 → **20/20，无回归**。
- 关键证据：绘制态 530 条 `.leaflet-interactive` PE 全 `none`，退出后复原 `stroke`；
  Canvas 基线 `onFeatureClick` 1 次 → 绘制态 0 次，同时顶点仍落下。
