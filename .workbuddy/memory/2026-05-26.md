## GitHub Actions COS 部署踩坑
- coscli `config init` 是交互式的，CI 中不能用 `-a/-s/-b/-r` flag，会触发交互流程吞掉参数
- coscli 首次运行检测无配置文件时强制交互初始化，`config set -i/-k` 也无效
- 解决方案：直接写 `~/.cos.yaml` 配置文件绕过交互
- coscli `sync` 没有 `--parallel` flag，正确参数是 `--routines`（文件间并发）
- coscli `--delete` 必须配合 `--recursive` 一起用
- 最终改回 coscmd 方案：`coscmd upload -rs . / --ignore './.git/*'`，稳定可靠
- coscmd `-s` 是增量同步（比对 MD5，跳过未修改文件），不加 `--delete` 则 COS 旧文件不清理
