# 2026-06-06

## Shapefile 中文乱码问题 — 最终总结

### 结论

**本次问题主要是数据问题，不是前端问题。**

### 关键发现

1. `shp.min.js` 读取 `.cpg` 文件后，用 `TextDecoder` 解码
2. 浏览器 `TextDecoder` 不支持 `GB2312`，只支持 `GBK`
3. 但 `shp.min.js` 没有做 `GB2312` → `GBK` 的映射
4. 所以 `.cpg` 存在但内容为 `GB2312` 时 → 解码失败 → 回退 UTF-8 → 乱码

### 尝试过的方案（效果均不理想）

- **方案 1**：修改 `shp.js`（未压缩版）→ 无效，实际运行 `shp.min.js`
- **方案 2**：`geojsonloader.js` 中注入 `.cpg` 文件 → 不靠谱，无法可靠判断编码
- **方案 3**：`handleFolderUpload` 中对每个 .shp 重新打包配套文件 → 本应有效但实际测试不生效
- **方案 4**：`index.html` 中 zip 上传逻辑对齐文件夹上传 → 未测试

### 判断

- 前端不适合处理编码检测/修正问题
- 单个 `.shp` 压缩成 `.zip` 上传时，`shp(buffer)` 自己解压找配套文件，逻辑是完备的
- 如果 `.cpg` 内容是 `GB2312`，这是数据源的问题，应该在数据端解决
- 最好的处理方式：**如果已知中文乱码，用文本编辑器将 `.cpg` 文件内容改为 `GBK` 或 `UTF-8`**

### 后续建议

- 前端可以保留 `companionExts` 扩展到 8 个文件的改动（无害）
- 前端可以保留对 `.cpg` 缺失/内容为 `GB2312` 的警告提示（有用）
- 但不要指望前端能完美解决编码问题
- 需要改的是 `shp.min.js` 的 `createDecoder`（如果允许修改第三方库的话）

## 图层组重构：自定义 div → `<details>` + `<summary>`

### 改动动因

- 用户提出是否改用 `<details>` + `<summary>` 实现图层组折叠
- 同时修复"地图控制"折叠区与搜索栏重叠的问题
- 优化整体侧边栏 CSS 布局

### 变更详情

**geojsonloader.js — `generateLayerItems()`：**

- 图层组容器从 `<div class="layer-group">` → `<details class="layer-group">`
- 组头部从 `<div class="layer-group-header">` → `<summary>`
- 子项容器 `<div class="layer-group-children">` 不变（放在 `<summary>` 后面）
- 普通点击折叠/展开由浏览器原生处理，不再需要 JS toggle
- Ctrl/Cmd+点击 → `e.preventDefault()` 阻止原生 toggle，手动操作所有 `details.open`
- 总开关全选 → `details.open = true` 替代 class toggle
- 组全选勾选 → `groupDetails.open = true` 替代 class toggle
- 箭头旋转 → CSS `details[open] .layer-group-arrow` 自动控制，无需 JS

**geojsonloader.css：**

- `.layer-group-header` → `details.layer-group > summary`
- `.layer-group-arrow.open` → `details.layer-group[open] .layer-group-arrow`
- 移除 `max-height: 0 / 600px` 动画（用户说动画不重要）
- `.layer-group-children` 简化为 `overflow: visible; margin-top: 2px;`
- 隐藏浏览器原生 `::-webkit-details-marker`

**main.css — 侧边栏布局优化：**

- `.layer-panel` 添加 `gap: 6px` 统一子元素间距
- `.layer-panel` padding 从 `15px 10px` 改为 `12px 10px 8px`
- `.search-bar` 添加 `flex-shrink: 0`，移除旧的 `margin-bottom`（由 gap 统一管理）
- `.toggle-section` 移除旧的 `margin-bottom`（由 gap 管理）

### 实现可行性

使用 `<details>` + `<summary>` 实现图层组方案完全可行，且代码更简洁：

- `details.open = true/false` 等效于之前的 class toggle
- 浏览器原生处理键盘无障碍（Enter/Space 切换）
- 所有现有逻辑（总开关、组全选、Ctrl+点击全部切换）均可直接映射
- 总计改动了约 120 行 JS 和 50 行 CSS

### 目标

把原有的 2 个开关（聚类/标签）放入 `<details>` 折叠区，新增编辑测量、鼠标坐标、缩放控件、比例尺、图层控件 5 个开关，所有开关持久化到 localStorage。

### 文件变更

**index.html**：

- 替换 `.toggle-bars-row` 为 `<details class="toggle-section" id="toggleSection">`
- `<summary>🌐 地图控制</summary>` + `.toggle-body` 容纳所有开关
- 新增 5 个 toggle bar：
  - `geomenToggle` — 编辑测量工具
  - `mouseCoordToggle` — 鼠标坐标指示
  - `zoomToggle` — 缩放控件
  - `scaleToggle` — 比例尺
  - `layerCtrlToggle` — 图层控件
- 控件创建时存入变量：`scaleControl`、`mousePosControl`、`layerCtrlControl`
- 新增 IIFE 实现 toggle 持久化逻辑：
  - `dupal_toggle_` 前缀存储各开关状态
  - `dupal_toggle_sectionOpen` 存储折叠区展开/收起状态
  - 各开关在 change 事件中 add/remove 对应控件
  - Geoman 通过 `map.pm.addControls/removeControls` 切换
  - 其他标准控制通过 `map.removeControl()/control.addTo(map)` 切换

**main.css**：

- 替换 `.toggle-bars-row` 样式为 `.toggle-section` + `summary` 样式
- 自定义 `::-webkit-details-marker` 隐藏原生三角，用 `▶` + 旋转动画替代
- `.toggle-body` 内 `.cluster-toggle-bar` 垂直堆叠布局

### 关键决策

- 开关持久化顺序：控件先按默认状态创建 → 再读取 localStorage 决定是否移除（而非反向），保证首次加载时控件完整初始化
- 折叠区默认展开（`open`），状态同样持久化
- 聚类/标签开关仍由 geojsonloader.js 的 `initClusterToggle`/`initLabelToggle` 管理
- localStorage key 统一 `dupal_toggle_` 前缀，避免与原有 `clusterEnabled`/`labelEnabled` 冲突
