## Leaflet.MousePosition.js — 全屏按钮改为 PWA 感知逻辑

### 需求
原本点击全屏图标直接进全屏，改为三种状态：
1. 未安装 PWA（浏览器触发 `beforeinstallprompt`）→ 点击唤起原生安装弹窗
2. 已安装 PWA（`display-mode: standalone`）且非 iOS 手机 → 点击全屏/退出全屏
3. 已安装 PWA + iOS 手机浏览器（`iPhone|iPod`）→ 不显示图标（已是 standalone 全屏体验，无需操作）

### 改动文件
- `assets/Leaflet.MousePosition.js`：
  - 新增 `_isIOSPhone` 检测（区分 iPhone/iPod 与 iPad）
  - `onAdd` 中读取 `window._pwaInstallPrompt`（全局缓存的安装事件）
  - 检测 `display-mode: standalone` 判断是否已安装
  - iOS 手机已安装：不绑定点击事件，不显示图标
  - 点击路由：`_onActionClick` → 优先安装 → iOS引导 → 全屏
  - 监听 `beforeinstallprompt` / `appinstalled` 动态更新状态
  - 图标：安装中=⊕，iOS未安装=⬆，全屏=⛶，退出=✕
- `assets/Leaflet.MousePosition.css`：新增 `.lmp-pwa-hint-*` 居中弹窗样式
- `index.html`：在 `<head>` 最早位置监听 `beforeinstallprompt`，存入 `window._pwaInstallPrompt`

### 关键 API
- `beforeinstallprompt`：浏览器在"可安装但未安装"时触发，调用 `e.prompt()` 唤起安装弹窗
- `window.matchMedia('(display-mode: standalone)').matches`：判断是否以 PWA 模式运行
- `window.navigator.standalone === true`：iOS Safari standalone 检测

## Canvas 聚类算法：从 DBSCAN → Grid 网格预聚合

### 问题
45万点聚类卡顿，原 DBSCAN 聚类（RBush + BFS + `Math.sqrt()`）复杂度 O(n²)。

### 方案
Grid 网格预聚合（O(n)）：按 `clusterRadius` 划分屏幕网格，每个格子内点聚合为 cluster，只需一次遍历，无递归、无树、无开方。

### 改动
- **`assets/Leaflet.MarkersCanvas.js`** `computeClusters` 函数：完全重写为网格预聚合
  - `clusterRadiusPixels = 100`（从 60 调大，减少 cluster 数量）
  - 单点保留原始坐标（而非质心偏移），避免视觉漂移

## Canvas 聚类 Grid 边界修复 + Cluster 点击居中

### 问题1：聚类过多（格子边界切开本应聚合的点）
原版 Grid：格子大小 = 聚类阈值(100px)，点落在格子边缘时被切开分散。

### 方案：Grid + 邻格合并
- 格子大小 = 阈值/2（50px），粒度更细
- 每格聚合后，额外查周围一圈邻格（3×3），若邻格质心在本格聚类半径内则合并
- 避免开方：用 `distX² + distY² <= radius²`

### 问题2：cluster 点击放大到地图中心
`setZoom(+2)` 只改缩放级别，地图中心不变，用户看不到想看的 cluster。

### 方案
- `hitItems` 新增 `screenX/screenY`（存储在 hit 检测树中）
- Cluster 点击：用 `L.point(hit.screenX, hit.screenY)` + `containerPointToLatLng` 算出质心经纬度，`setView(clusterLatLng, targetZoom)` 真正居中放大

### 改动
- `computeClusters`：格子大小=阈值/2，邻格合并逻辑，平方距离判断
- `_redraw` hit 构建：单点和 cluster 均加 `screenX/screenY`
- `_fire` cluster 分支：`setView(clusterLatLng, targetZoom)` 居中放大
- `geojsonloader.js`：补 `properties` 到 `featuresArray` 元素（弹窗需要）
