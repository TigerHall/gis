## 第三轮：出图「有要素没底图」根因 + AI 出图闭环（v3.4.3）
用户第二张截图（欧亚构造图）：上方横贯紫色平板 + 没有底图。逐项排查结论：
1. **紫色平板 ≠ 引擎 bug**：`plate16` 极冠环沿 ±180° 切开、靠 lat=90 顶点闭合，Mercator 钳到 ±85.05 后那条横移段正好落在世界上下边上 → 单独看像「平板」。复现脚本 `repro_user.js`（只开 plate16+volcanos、A4W/150dpi、全球视野）现在出图正常：一个世界、有底图、无平板带。老三件（世界副本 / 越界白带 / 无 warnings）已由上一轮护栏 + 提示收口。
2. **没有底图 = 真 bug（已修）**：`drawImageOverlay` 里 `latToY(clampLat(b.getNorth().lat))` —— `getNorth()` 返回**数字**，`.lat` 是 undefined → NaN → `drawImage(im,x,NaN,w,h)` **静默不画**，但函数仍 `return {ok:1}`。ETOPO / ETOPO_2022 因此整幅空白而报告「底图成功」。用 `dbg_etopo2.js`（拦截 `CanvasRenderingContext2D.prototype.drawImage`）抓到 `args:[-1421, null, 2489, 2489]` 才定位。
   - 同函数顺带修：副本序号 `round` → `floor`（中心经度 >0 时整幅影像被平移一个世界）；改成逐份 k-1..k+1 只画与画布相交的。
3. **底图失败不再静默**：`drawXYZ` 全失败 / 部分失败≥30%、`skipped`（Esri 历史影像无静态瓦片地址）、影像加载失败，四类都写进 `report.warnings`。实测 OSM 12/12 失败、Esri skipped、ETOPO 修后 100% 非白。
4. **AI 预览与成品同源**：`_previewExport` 以前直接 `MapExport.render(模型参数)`，`preset:"a4w"` 只是 UI 概念 → 纸面永远默认 170mm。新增 `MapExport.resolveOpts(opts)`（与 `exportNow` 同一套 `_mergeOpts`+`buildOpts`，但不改 state、不开面板），预览 = 成品参数。
5. **`export_image` 等渲染完再返回** `{file,width,height,frame,zoom,warnings}`，模型能讲清构图并自行纠错；tool-calling 轮数 5→8，触顶改用 `_apiRequest(messages,{noTools:true})` 收尾总结（原来是甩一句「已停下」）。
6. **世界副本护栏失效的真因**：`fitBounds` 默认带缩放动画，动画期间 `getBounds()` 是中间态 → 判定「没超 360°」直接跳过。`_fitBoundsSafe` 改 `animate:false`；`_clampWorldSpanSoon` 改「`moveend` 后再量 + 6s 兜底」（懒加载可能 10s 后才 fitBounds）。
- 端到端（真实 deepseek）跑通：`get_map_state → toggle_layer → set_view → preview_export → 自然语言总结`，缩略图 760×471 贴进对话，零报错；总耗时 ~18s（渲染占了 8s）。
- SW CACHE_NAME bump → v3.4.3。
