## 图层组小分组（通用能力）+ 地质站位组重整（v3.1.2 → v3.2.0）

### 一、`subgroups` 通用字段

`geo-config.js` 的 group 新增 `subgroups`（与 group 同构，可无限嵌套）：

```js
{ groupName: "X", layers: [...], subgroups: [ { groupName: "Y", layers/subgroups } ] }
```

引擎改动（`geojsonloader.js`）：
- 把原来 `group.layers.forEach` 的整段抽成 `buildLayerItem(layerConfig, groupName, pathName, container)`；
  新增 `buildSubgroup(sub, parentGroup, container, depth)` 递归渲染。
- **不写 `subgroups` 的组行为完全不变**（同一条 `buildLayerItem`）。
- 小分组 DOM **沿用** `.layer-group` + `.group-select-all` + `.group-status`
  → `syncGroupStatus` / `syncGroupLoadingStatus` / `syncAllGroupStatus` 全是后代选择器
  `querySelectorAll`，**天然覆盖嵌套**，没为嵌套另写一套同步。

**踩到/修掉的两个「假设只有一层」的老逻辑**（这是嵌套功能真正的坑）：
- `expandToLayerGroup()` 用 `cb.closest("details.layer-group")` 只展开**最近一层**
  → 改成 `while (node = node.parentElement)` 逐级向上。
- `updateLayerItemStatus()` 同样用 `closest(".layer-group")` → 父组状态点不刷新
  → 改成逐级向上，对每个含 `.layer-group` 的祖先都同步。
- Ctrl/Cmd+点 summary「全部收起/展开」的判据 `details.layer-group[open]`
  要加 `:not(.layer-subgroup)`，否则展开过某个小分组会让「全部收起」像「全部展开」。
- `geo-utils.js` 的 `getLayerPopupConfig()` 原本只扫 `group.layers` **一层**
  → 改递归 `walkGroup`，否则小分组里图层的 `popup.hideFields` 静默失效。

**搜索**：`searchRegistry` 的 `groupName` 存**完整路径**（`地质站位 › 印度洋`），
所以搜「印度洋」「洋中脊」能命中组内图层；`checkbox.dataset.groupName` 同步用该值。

视觉（`main.css` `details.layer-subgroup`）：去卡片外框、缩进一级、名字用次级文字色。
实测对比度 浅 5.27:1 / 深 7.64:1，过 AA。
