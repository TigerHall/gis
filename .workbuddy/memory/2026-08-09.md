# 2026-08-09 工作日志

## iOS 地图状态持久化可靠性修复

**问题**：iOS Safari 上关闭再打开页面，地图缩放/位置没有恢复到最新状态（恢复的是旧位置）。根因是地图状态（中心 + 缩放）仅依赖 `pagehide` 事件保存，iOS 上 `pagehide` 不可靠（切后台/锁屏可能不触发或来不及写 localStorage）。

**修复**（`assets/geojsonloader.js`）：
- 将单一 `pagehide` 保存升级为三层策略：
  1. `moveend` 防抖 500ms — 用户操作停止后自动保存（主力，实时落地）
  2. `visibilitychange` → hidden — 页面隐藏时立即保存（iOS 上最可靠的"离开"信号）
  3. `pagehide` — 标准导航离开兜底
- 新增 `_mapStateReady` 标志位，初始化完成前禁止保存，防止 visibilitychange 在恢复弹窗期间把默认中心坐标写入覆盖旧值
- 抽取 `saveMapState()` 独立函数，所有保存路径复用
