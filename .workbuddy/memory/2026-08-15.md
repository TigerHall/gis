## 备案号改左下角 + 格网标签移到地图外侧

**实测发现**：#map 用 `flex:1` 占满整个 body 内容区，宽度实际是 `100vw - 2*bodyPadding`，桌面端左右外侧只剩 8px padding —— 放不下任何坐标文字（"120°E" 11px ≈ 30px）。

**改动（5 处）**：
1. `assets/Leaflet.Graticule.js`：DPR 高清适配（`_reset` 里 canvas.width × dpr；`__draw` 里 `ctx.setTransform(dpr,0,0,dpr,0,0)` 配合 `ctx.clearRect` 用原始像素）。解决"糊"的根因。
2. **新增** `assets/graticule-labels.js`：DOM 边缘坐标标签层（替换插件内置 showLabel）。fixed 定位在 body 下，`pointer-events:none`、z-index 1050。监听 moveend/zoomend/viewreset + window resize 重算。格式 `120°E`/`30°N`。MIN_GAP=26 防重叠。
3. `index.html` head 引入 `graticule-labels.js`（在 Leaflet.Graticule.js 后）。
4. `assets/app.js` graticuleToggle：`showLabel:false`、enable 里 `#map.classList.add('graticule-active')` + `map.invalidateSize()` + `GraticuleLabels.enable(...)`；disable 同步清理。深色联动走 `setDark`（标签层只换主题、不重建）。
5. `assets/main.css`：`#map.graticule-active { margin: 20px 40px !important; height: calc(100% - 40px) !important; }`（窄屏 <768px 缩到 12/8）；`#beianBar { bottom:30px; left:8px; }`（备案号改左下角，bottom:30 避开底部坐标标签行）。

**关键决策**：格网开 → 地图让出 40px 边距；标签 → DOM 渲染（彻底解决 canvas 糊）。备案号 z-index 1100 > 标签层 1050，标签 pointer-events:none 不挡点击。

**验证**：playwright-core 跑端到端断言全过：备案号 left:8 bottom:30；地图激活时 rect 从原 (8,8,1272,792) 缩到 (48,28,1232,772)；22 个标签全部 `labelsOutsideMap:true`；zoom6 标签按 5° 间隔更新；深色模式 `gl-dark` class 应用；关闭时 class/canvas/标签层全部清理；0 JS 错误。

- **格网插件配色**：浅色模式 `#6b6b6b` opacity 0.55；深色模式 `#9aa0a6` opacity 0.7（中性灰在两主题都清晰）
- **zoomInterval 分级**（适配海洋站位图视野）：1-3: 30°, 4-5: 10°, 6-7: 5°, 8-9: 1°, 10+: 0.5°
- **`latLineCurved: 4`**：Web Mercator 下纬线略弯，4 段折线贴合底图
- **深色模式联动**：插件不支持改色（无 setStyle），重建是唯一方式。在 darkModeToggle enable/disable 末尾调用 `rebuildGraticuleTheme()`（函数声明在 toggleConfig 之前）
- **控件避让**：底部坐标标签与右下角鼠标坐标控件轻微重叠（已知接受，可后续微调 font/padding）
