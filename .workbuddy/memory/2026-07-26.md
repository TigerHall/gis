# 2026-07-26

## 新增图例控件（Leaflet.LegendControl）

**新建文件**：
- `assets/Leaflet.LegendControl.js` — Leaflet 图例控件插件（`L.Control.Legend`）
- `assets/Leaflet.LegendControl.css` — 图例样式（深色/浅色主题适配）

**修改文件**：
- `assets/geo-utils.js` — 新增 `getFieldColorPalette(fk)` 公开方法（浅拷贝）
- `assets/geojsonloader.js` — 新增 `_buildLegendData()` / `_refreshLegend()` / `scheduleLegendRefresh()`，7 处图层变更钩子
- `assets/app.js` — `TOGGLE_GROUPS` 新增 `legendToggle`（默认开启），`toggleConfig` 新增 `legendToggle`（bottomleft 位置）
- `index.html` — `<head>` 引入 CSS + JS（在 Leaflet 主库之后、app.js 之前）
- `docs/CHANGELOG.md` — 追加图例功能记录

**功能要点**：
- 左下角显示当前可见 GeoJSON 图层的图例
- 支持：单色图层、字段分色图层（子项）、图标图层（emoji/外部图片）
- 15 项以上折叠、字段值 8 个以上折叠
- 地图设置开关控制显示/隐藏
- 图层勾选/取消/颜色模式切换均自动刷新

## 图例控件 v2：几何符号 + 可展开字段分色

**修改文件**：
- `assets/Leaflet.LegendControl.js` — 重写渲染逻辑
- `assets/Leaflet.LegendControl.css` — 新增符号/箭头/badge 样式
- `assets/geojsonloader.js` — `_buildLegendData()` 新增 `geomType`（点/线/面）+ `mode` 字段

**核心改进**：
- **几何符号差异化**：点要素用 SVG 圆形、线要素用横线、面要素用方块色块
- **字段分色可展开**：用 `<details>` 原生折叠，点击图层名展开/收起子项（▶ 箭头动画）
- **模式标记**：sequential 图层显示「多色」badge，field 图层显示「N 色」badge
- 所有图层（不论颜色模式）均显示在 legend 中
- 子项颜色继承对应几何符号（点/线/面）的小尺寸版本
