# 2026-05-22 工作记录

## 拖入文件夹支持
`index.html` 的 drop 事件处理升级：
- 通过 `e.dataTransfer.items[i].webkitGetAsEntry()` 检测是否为目录
- 目录：递归扫描 `FileSystemDirectoryEntry`，收集所有文件后走文件夹上传逻辑（`_folderUploadMode`，默认不显示）
- 单文件：走原有 `loadFileAsUserLayer` 通道（默认显示）
- 单文件拖入过滤掉裸 `.shp`（无配套文件无法解析）

## 文件夹上传支持裸 SHP 文件
`handleFolderUpload` 新增 `.shp` 文件支持：
- 从 `allFiles` 建立 `fileMap` 查找表，按 baseName 匹配配套 `.dbf`/`.shx`/`.prj`
- 用 JSZip 将配套文件打包成内存 zip → ArrayBuffer → 喂给 `shpjs` 的 `shp(buffer)` 解析
- 缺少配套文件不阻断，记录到 `warnings` 数组，最后统一 alert 提示
- 非 shp 文件（kml/kmz/json/geojson）照旧走 `loadFileAsUserLayer` 通道
- shp 解析直接调 `window.addUserLayer` 添加图层，不走 `loadFileAsUserLayer`（后者不支持裸 .shp）
- 图层名用 `.shp` 自身文件名，多图层时加 `_0`/`_1` 后缀

## 文件夹上传默认不显示图层
- `addUserLayer` 新增第三个参数 `autoShow`（默认 `true`）
- `loadFileAsUserLayer(file, autoShow)` 和 `deliverToMap(data, fileName, autoShow)` 同步透传
- 文件夹上传时显式传 `false`，不再使用全局 `_folderUploadMode` 标记（已废弃，存在时序 bug）
- `autoShow=false` 时：图层缓存到 `layerCache` 但不 `addTo(map)`，checkbox 不勾选
- 单文件上传不受影响（不传 autoShow，走默认 `true`）

## 强制刷新：自定义选项对话框（三选项）
版本号双击/双 tap 弹出自定义对话框，三个选项：
- 仅清空 SW 缓存
- 清空 SW + GeoJSON 数据库（IDB）
- 取消
对话框用纯 JS 创建 overlay + dialog，CSS 仿 iOS ActionSheet 风格，不依赖第三方库。

## 强制刷新：增加 IDB 清空（已合并到上面）
版本号双击/双 tap 强制刷新逻辑升级：
- 原来只清空 SW 缓存（`caches.keys()` + `caches.delete`）
- 现在同时清空 GeoJSON IDB 缓存（`L.GzIdbLoader.clearCache()`，数据库名 `GzGeoJSONCache`）
- 两个任务 `Promise.all` 并行，全部完成后 `location.reload(true)`
- 兜底：如果 `L.GzIdbLoader` 未初始化，直接用 `indexedDB.deleteDatabase("GzGeoJSONCache")` 删库
- 提示文案同步更新为"将清空 SW 缓存和 GeoJSON 本地数据库"
