## 要素详情面板（属性表 + ECharts 图表）

**时间**：2026-08-01  
**文件变更**：

- 新建 `assets/feature-panel.js` — 面板核心逻辑（约 500 行）
- 新建 `assets/feature-panel.css` — 面板样式（约 300 行）
- 修改 `index.html` — 面板 HTML 容器 + Popup「查看详情」按钮注入 + ECharts CDN 懒加载
- 修改 `assets/geo-utils.js` — 新增 `extractNumericFields()` 和 `computeLayerStats()` 工具函数
- 修改 `assets/geojsonloader.js` — 暴露 `featureCache`、`_layerIdByFileName`、全局入口函数 + 图层 📋 按钮

**两种入口**：

1. **单要素模式**：点击要素 → Popup → [📋 查看详情] 按钮 → 面板显示该要素属性（翻页，15条/页）
2. **图层模式**：图层面板每个图层新增 [📋] 按钮 → 面板显示该图层全部要素表格（翻页搜索）

**图表功能**：

- ECharts 从 CDN 懒加载（https://cdn.jsdelivr.net/npm/echarts@5.5.1/dist/echarts.min.js）
- 默认柱状图，支持切换雷达图、饼图
- 支持「对比图层均值」复选框
- 自动识别数值字段

**关键设计**：

- 面板右侧滑出（CSS transition `transform: translateX`）
- Canvas 要素通过 `popup._featureRef/_layerId` 传递要素引用
- 非 Canvas 要素通过 `popup._source.feature` + `featureCache` 反向查找
- 内置 `_layerIdByFileName` 反向映射加速查找
