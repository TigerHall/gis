## Cesium 3D 代码实现

- `assets/cesium-viewer.js` — Cesium Viewer 懒加载初始化（CDN v1.125）、相机同步（Leaflet zoom↔Cesium height 公式）、图层编排（activate/deactivate/addLayer/removeLayer/syncAllLayers）、底图映射（天地图/ArcGIS/GEBCO/OSM → Cesium ImageryProvider）

## Cesium 3D Bug 修复

### Bug 1: Cartesian3 undefined（根因 + 修复）

- **根因**：`cesium-viewer.js` line 143 写成 `Cesium.Cartesian.fromDegrees`（缺少 `3`），正确应为 `Cesium.Cartesian3.fromDegrees`。`Cesium.Cartesian` 不存在 → `undefined.fromDegrees()` → TypeError
- **修复**：添加 `getCartesian3()` 函数，优先用 `window.Cesium.Cartesian3`，回退从 `viewer.camera.position.constructor` 获取构造器，最终回退 `flyTo + destinationCartographic`
- **附加**：所有 bare `Cesium.` 引用改为 `window.Cesium.`；添加 API 可用性诊断日志

### Bug 2: Entity geometry outlines unsupported on terrain

- **根因**：贴地面要素设置 `outline: true` → Cesium 不支持地形贴附几何的 outline
- **修复**：`clampToGround` 时 `outline = false`；仅非贴地时启用 outline

### Bug 3: markerSize 使用 Cartesian2（不必要依赖）

- **修复**：`Cesium.Cartesian2.fromElements(size, size)` → 直接传数值 `pointPixelSize`

## Cesium 3D 交互增强（第二轮）

### 修复：3D 下交互失效

- **缩放至按钮失效**：`__OGV_highlight`（highlightAndLocateFeature）走 Leaflet setView/fitBounds，3D 下无效。新增 `CesiumViewer.flyToFeature(feature)`（computeGeometryBounds 包围盒 + flyTo 点/矩形），`highlightAndLocateFeature`、feature-panel `_bindZoomButtons` 均检测 `CesiumViewer.isActive` 路由到 3D
- **缩放至导致图层关闭**：feature-panel 缩放至原复用 `__OGV_highlight` → `_isolateToLayer` 关闭全部图层。改为直接 `_extractFeatureCenter` + setView（2D）/ flyToFeature（3D），不再隔离
- **多颜色渲染失效**：`reloadLayerWithNewMode` 只更新 2D，无 Cesium 通知。新增 `CesiumViewer.reloadLayer(checkboxId)`（移除+重建数据源），在 `reloadLayerWithNewMode` 顶部调用
- **选中弹窗失效**：Cesium 无点击拾取。新增 `setupClickHandler`（ScreenSpaceEventHandler LEFT_CLICK + scene.pick），adapter 在 entity 上存 `_ogv={layerId,featureIndex,fileName,layerName}`，`showEntityPopup` 复用 `GeoUtils.buildPopupContent` + 缩放/详情按钮

### 颜色一致性

- adapter `getFeatureColor` 改为复用 `GeoUtils.getFeatureColorByIndex/Field`（与 2D 完全一致）；`hexToColor` → `parseColor` 用 `Color.fromCssColorString` 兼容 hex/rgb/hsl

### 底图 3D 联动

- `index.html` 暴露 `window._currentBasemapName`，`baselayerchange` 时若 3D 激活则调 `CesiumViewer.syncBasemap()`
- `cesium-container.css` 3D 下不再 `display:none` 隐藏 #map，改为隐藏 `.leaflet-pane`（瓦片/矢量）+ 隐藏非图层控件（`.leaflet-control` 除 `.leaflet-control-layers`），`pointer-events:none` 防拦截 3D 交互；底图切换控件在 3D 下仍可见可点

## Cesium 3D 第三轮修复

### ArcGIS-影像底图报错（getDerivedResource）

- **根因**：`ArcGisMapServerImageryProvider` 在 Cesium 1.125 CDN 构建下有已知 `getDerivedResource` undefined bug（`Rendering has stopped`）
- **修复**：改用 `UrlTemplateImageryProvider` 直接访问 ArcGIS 瓦片端点 `tile/{z}/{y}/{x}`（天地图同款 Provider，稳定）

### 图层加载慢（重复移除+添加）

- **根因**：`addLayer` 原来「已存在则先移除」，`syncAllLayers` + `onDataLoaded` 钩子 + `reloadLayer` 对同一图层重复触发 → 多次 remove+add 闪烁
- **修复**：`addLayer` 改为幂等（已存在则跳过）；`reloadLayer` 仍显式 remove+add 重建

### 3D 开关状态不一致（刷新后开关仍开）

- **根因**：`view3dToggle` 状态持久化到 localStorage，页面刷新后 `initToggle` 恢复为勾选，但 `enable(false)` 因 `userInitiated=false` 提前返回不激活 3D → 开关开、界面 2D 矛盾
- **修复**：`view3dToggle` 加 `noPersist:true`；`initToggle` 对 noPersist 开关不读 localStorage、默认回未勾选、change 时也不写入

### 3D 提示条改为弹窗组件（第四轮微调）

- 移除 `#cesiumModeIndicator` DOM 元素 + `cesium-mode-hint` CSS 动画（原为持久化常驻提示条）
- 改用 `showToast("🌍 3D 视图 — 拖拽旋转 · 滚轮缩放 · 右键倾斜", { duration: 5000 })` 弹窗显示 5s 自动消失
