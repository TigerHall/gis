# 2026-07-20

## 新增「高程读取」插件 + 设置开关
- 新插件 `assets/Leaflet.ElevationQuery.js`（标准 Leaflet 插件，`L.Class`+`L.Evented`）：点击地图查询任意坐标高程/水深。
  - 数据源可配置：`source:'gebco'`（默认，WMS GetFeatureInfo）｜自定义函数 `{query(latlng,ctx)}`｜`{type:'wms',...}`。运行时可 `eq.setSource(...)` 切换（满足"后续换高程源"）。
  - 单例挂载 `map.elevationQuery({source})`；`enable()/disable()/query(latlng)`；事件 `enable/disable/querystart/result/error`。
  - UI：底部居中信息栏 `.elev-query-bar` + 点击点弹窗 `.elev-popup`，复用站点设计语言（绿色描边、圆角、feature-popup 表格式、CSS 变量自动深色）。
- 配套样式 `assets/elevation-query.css`。
- 开关：在 `app.js` 的 `TOGGLE_GROUPS`「高级」分类新增 `elevationReadToggle`（默认关闭），`toggleConfig` 新增对应 `enable/disable`（懒加载 `ensureElevationQuery()` 单例）。
- `index.html` 引入 css（head）与 js（app.js 前）。
- 注意：默认 gebco 源忠实沿用用户样例的 WMS 1.3.0 + CRS=EPSG:4326 + toBBoxString(lon,lat) 参数；若日后发现跨子午线/高纬 I/J 偏移，可改 `version:'1.1.1'`+`SRS` 或自定义源。
