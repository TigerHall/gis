# 2026-07-15

## GZ 文件解析支持

- `assets/file-handler.js` 新增 `.gz` 格式解析支持，覆盖所有入口：
  - **单文件**：`loadFileAsUserLayer` 新增 `.gz` 分支，用浏览器原生 `DecompressionStream("gzip")` 解压后自动识别内部 .geojson/.json/.kml
  - **ZIP/KMZ 内部**：循环识别 `.gz` 条目 → `geojsonGzFiles` / `kmlGzFiles` → 解压后投递
  - **文件夹扫描**：`"gz"` 加入 `nonShpExts`，`.gz` 文件自动回调 `loadFileAsUserLayer`
  - **拖放**：正则中补充 `gz`，非文件夹拖放也支持 `.gz`
  - 所有提示信息同步更新
- 新增工具函数 `decompressGz(arrayBuffer)`，封装 `Blob.stream().pipeThrough(DecompressionStream)` + `new Response().arrayBuffer()` 链

## PWA 关联打开 .gz

- `manifest.json`：`file_handlers.accept` 新增 `"application/gzip": [".gz"]`
- `index.html`：文件选择器 `accept` 新增 `.gz,application/gzip`
- 配合 `file-handler.js` 已有的 `launchQueue` + `loadFileAsUserLayer` 逻辑，`.gz` 文件被 OS 唤起 PWA 时自动解压并加载

## 图层透明度控制

- `geojsonloader.js` 新增透明度控制功能：
  - **`layerOpacityMap`** — 存储每图层不透明度（0-1，默认 0.8）
  - **`getGeoJsonStyle`** — 从 `layerOpacityMap` 读取 opacity 替代硬编码 0.8
  - **对话框** — `getColorPanelHTML` 新增不透明度滑块（0-100%），拖动时实时显示百分比
  - **保存** — 确认按钮读取滑块值，写入 `savedSettings.opacity` 持久化
  - **`reloadLayerWithNewMode`** — 新增 `newOpacity` 参数，DOM 图层直接 `setStyle` 刷新（免重建），Canvas 图层暂存 opacity
