## 导出地图图片方案演进

### 问题根因
线/面在 SVG 层渲染，Leaflet 用 `transform: translate3d(...)` 实现平移。
`html2canvas` 不是真正截图，而是自己解析 DOM 再 Canvas2D 重绘，对 CSS transform + SVG 坐标转换处理有 bug，导致线/面偏移。
点要素走 Canvas 插件直接绘图，不经过 SVG pane，所以不受影响。

### 方案演进

| 版本 | 方案 | 问题 |
|------|------|------|
| v1 | `html2canvas` | transform/SVG 偏移 bug，线/面位置错误 |
| v2 | `window.print()` + `@media print` | 页眉页脚无法代码去除，移动端体验差 |
| v3 | `dom-to-image-more` v3.7.2 | 把 SVG `<use href="#id">` 的片段引用当成 HTTP 请求，404 风暴，卡且画质低 |
| **v4（当前）** | **`html-to-image` v1.11.11** | 控件节点在截图前真的从 DOM 移除，`html-to-image` 克隆时看不到它们，404 问题彻底解决 |

### 当前实现（v4）

**`index.html` `exportMapImage()` 函数：**
1. 把 `.leaflet-control-container` 的子节点**真的 `removeChild()` 移除**（不是 `display:none`），存入 `removedEls[]`
2. 隐藏侧边栏和 trigger（`display:none`）
3. 调用 `htmlToImage.toPng(mapEl, { backgroundColor: "#fff", pixelRatio: Math.min(devicePixelRatio||2, 3) })`
4. `.then()` / `.catch()` 里用 `insertBefore` / `appendChild` 恢复所有移除的节点
5. 触发 `<a>` 下载 `OGV_HHMMSS.png`

**文件变更：**
- `assets/html-to-image.min.js`：新增，v1.11.11，19853 bytes
- `index.html` 第 35 行：`<script src="./assets/html-to-image.min.js">`
- `index.html` `exportMapImage()`：完整替换
- `assets/dom-to-image-more.min.js`：待删除
- `assets/html2canvas.min.js`：已删除
- `assets/main.css`：`@media print` 样式保留（供 Ctrl+P 手动打印）

### 关键技术点
- **为什么 `display:none` 不够？** `html-to-image` 克隆 DOM 后递归处理 SVG 子元素，即使父元素不可见，SVG `<use>` 引用仍会被处理，导致 404
- **为什么 `filter` 选项不够？** `filter` 只决定是否处理某个节点，但 `html-to-image` 的 SVG 处理是递归的，父节点被过滤不代表子节点不被处理
- **真正的修复**：`removeChild()` 让这些节点完全不在 DOM 里，`html-to-image` 克隆时根本看不到它们

## 导出地图图片方案 v5（修复 insertBefore 报错）

### 问题根因
v4 方案在截图前 `removeChild()` 摘掉控制节点，截图后 `insertBefore` 恢复。但截图期间 DOM 可能重排，导致记录的 `nextSibling` 不再是父节点的子节点，报 `NotFoundError`。

### v5 修复方案
彻底删除 remove/restore，改用 `html-to-image` 的 `filter` 回调排除控制节点。节点留在 DOM 里，不会出现在截图中，也无需恢复。

**`index.html` `exportMapImage()` 变更：**
- 删除：摘节点的代码（`removedEls[]` 及 `removeChild`）
- 删除：`then()` / `catch()` 里的 `insertBefore` / `appendChild` 恢复逻辑
- 保留：`filter` 回调已排除 `.leaflet-control-container` 等控制节点
- 保留：侧边栏 `display:none` 隐藏（面板不在地图容器内）

**`filter` 回调（已在代码中）：**
```javascript
filter: function (node) {
  if (!node || !node.classList) return true;
  if (node.closest) {
    return !node.closest(".leaflet-control-container, .leaflet-control, .leaflet-popup, .leaflet-tooltip");
  }
  return true;
}
```

### 方案对比表

| 版本 | 方案 | 问题 |
|------|------|------|
| v1 | html2canvas | transform/SVG 偏移，线/面位置错误 |
| v2 | window.print() + @media print | 页眉页脚无法去掉，移动端体验差 |
| v3 | dom-to-image-more | SVG `<use>` 当 HTTP 请求，404 风暴 |
| v4 | html-to-image + removeChild | 恢复时 insertBefore 报错 |
| **v5（当前）** | **html-to-image + filter 回调** | 节点不离开 DOM，无恢复问题 |

### 关键结论
- `filter` 返回 `false` 的节点不出现在输出图像中，但仍在 DOM 里
- 不再需要 remove/restore，从根本上避免了 DOM 状态不一致的问题
