# 2025-05-22

## 多格式文件上传（GeoJSON / SHP / KML / KMZ / ZIP）
- CDN 引入 shpjs（unpkg.com/shpjs@latest/dist/shp.js）、@mapbox/togeojson@0.16.2、JSZip@3
- `loadFileAsUserLayer` 逻辑：
  - **单文件**（geojson/json/kml）：统一走 `readAsText`，按扩展名选择解析器，图层名 = 原始文件名（带后缀）
  - **ZIP/KMZ**：`readAsArrayBuffer` + JSZip 解压，扫描内部文件：
    - `.shp` → shpjs 解析整个 buffer，图层名用 .shp 自身文件名（如 `plates.shp`）
    - `.geojson/.json` → JSON.parse，图层名用 ZIP 内文件名
    - `.kml` → toGeoJSON.kml，**KMZ** 用外层文件名（如 `data.kmz` → `data.kml`），**通用 ZIP** 用内部文件名
  - 三种类型可共存于同一 ZIP，Promise.allSettled 并行处理
- 修复 `isKmz` 变量未定义导致 KMZ 上传崩溃
- 修复 ZIP 内 KML 路径匹配问题（`zip.file(item.path)` 使用相对路径）
- 更新了 fileInput.accept 和拖放过滤正则

## KML GeometryCollection 三副本修复
- toGeoJSON 将 KML 的 `<MultiGeometry>` 转为 `GeometryCollection`
- `shiftGeometry` 新增 `GeometryCollection` 分支：递归偏移所有子几何
- `detectMainGeomType` 新增 `GeometryCollection` 处理：递归统计子几何类型
