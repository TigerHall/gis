### VectorGrid 重引 + 三种颜色模式功能重构

**问题背景：** 上次引入 VectorGrid.Slicer 导致要素渲染到底图下方（Canvas tile 层级低于 overlay），之前已回滚。本次重新引入并彻底修复层级问题。

**解决方案：**
- `L.vectorGrid.slicer` 使用 `rendererFactory: L.svg.tile` 代替默认 Canvas renderer，SVG tile 的渲染层级等同于普通 Leaflet overlay，底图（TileLayer）默认在其下方
- 保持三世界副本（-360/0/+360°）机制，确保跨子午线连续显示
- 要素 ID 机制（`_vgId`）保证三副本高亮同步

**新增颜色模式系统：**
- `colorMode[checkboxId]` = `"single"` | `"sequential"` | `"field"`
- `layerColorMap[checkboxId]` = 单色模式的基准色
- `fieldKey[checkboxId]` = 按字段分色模式的字段名
- `fieldColorPalette[fk]` = 字段值→颜色映射缓存（同值同色）

**图层管理面板改进：**
- 每个图层项新增 🎨 颜色设置按钮
- 点击弹出颜色模式选择面板（三种模式 radio + 颜色选择器 + 字段下拉框）
- 切换颜色模式后：清除旧图层 → 更新状态 → 重新加载
- 默认模式：`"sequential"`（内部多颜色，各要素黄金角分布不同色）

**已移除旧的 polygonColorConfig 硬编码配置**，现在颜色模式完全由用户通过 UI 控制。

**文件改动：**
- `index.html`：重新引入 `Leaflet.VectorGrid.bundled.min.js`
- `assets/geojsonloader.js`：完整重写，VectorGrid + 三色模式 + 颜色弹窗
- `assets/geojsonloader.css`：新增 `.layer-color-btn` + `.color-modal-*` 样式

**改动文件：**
- `index.html`：移除 VectorGrid script
- `assets/geojsonloader.js`：`buildGeoJsonLayerGroup` + 适配 L.geoJSON 的高亮函数

**Bug 修复（14:15）：**
- 问题：切换颜色模式后，旧配色残留
- 原因：`reloadLayerWithNewMode` 只清除了 `layerCache`，`highlightState` 中的旧图层副本（-360/0/+360° 三个）没有被从地图上移除
- 修复：在 `reloadLayerWithNewMode` 中，先强制移除 `highlightState.geoLayers` 中所有图层，再清除缓存
- 同步修复：`removeGeoJSONLayer` 也增加 `layerBoundsCache` 清理，保持一致性

**Bug 修复（14:23）：**
- 问题1：点要素（火山等）无法使用内部多颜色，只有单一颜色有效
- 原因：`getFeatureFillColor` 对非多边形直接返回单色，跳过了 sequential/field 逻辑
- 修复：移除该分支判断，让点线要素也走统一的三色模式逻辑

- 问题2：热点（hotspots.json）无法调整颜色
- 原因：`pointToLayer` 中硬编码 `createStarIcon("red")`，没有使用颜色模式
- 修复：改为使用 `getFeatureFillColor` 获取颜色参数，应用到所有热点图层创建处

**功能改进（14:29）：**
- 问题：点/线要素初始用多颜色，用户希望初始用单色
- 修复：添加 `detectMainGeomType` 函数检测几何类型，根据类型设置默认模式
  - 点/线要素 → 默认 single（单一颜色）
  - 面要素 → 默认 sequential（多颜色）
- 同步修复用户上传图层的默认模式

- 问题：单一颜色选择器需要点"应用"才能预览
- 修复：颜色选择器 change 事件直接触发 `refreshLayerColors` 即时更新图层
- 添加 `refreshLayerColors` 函数，遍历 highlightState 直接更新样式而不重建图层

**功能修复（14:38）：**
- 问题1：热点、火山还是默认多颜色，没有保持最开始的红色五角星和圆形
- 原因：`generateLayerItems` 中所有图层初始 `colorMode = "sequential"`
- 修复：热点/火山文件（`hotspots.json`/`volcanos.json`）使用固定红色 `#FF3333`，默认 single 模式
- 其他图层初始 single，加载时检测到面要素自动改为 sequential

- 问题2：断层（线要素）无法切换多颜色
- 原因：`getGeoJsonStyle` 中线要素 `fillOpacity: 0`，fillColor 不显示
- 修复：重构 `getGeoJsonStyle`，线要素使用 `color` 属性显示多颜色
- 重构后的逻辑：
  - 线要素：`color = featureColor`（多颜色边线），`fillOpacity: 0`
  - 点要素：`color = featureColor`，`fillColor = featureColor`，`fillOpacity: 0.8`
  - 面要素：`color: #555`（灰色边框），`fillColor = featureColor`（多颜色填充）
