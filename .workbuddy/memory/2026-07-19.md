- **修复点要素不受透明度控制的 bug**：根因是点要素用 `L.GeoMarker.createPointMarkerByType` 创建为 `L.Marker`+divIcon，无 `setStyle`，且 `getGeoJsonStyle` 给点返回的 opacity 从未传入。修复三处：(1) `createPointMarkerByType` 增 `opacity` 参数，烘焙进 divIcon 内层 `<div class="gm-op-wrap">`；(2) Canvas `_redraw` 用 `ctx.globalAlpha = options.opacity`；(3) 透明度滑杆更新循环对 marker 改 `.gm-op-wrap`/外层元素 opacity。
- **搜索首自动检索**：`runSearch` 增「第零阶段」优先检索 `searchPriority` 图层（即使未勾选也可搜，结果置顶），Phase 2 跳过 priority 避免重复；启动 2s 后后台静默 `L.GzIdbLoader.fetch`+`buildSearchIndex` 为 priority 图层建索引（不渲染到地图）。
- 新增配置项已验证：`geo-config.js` 加载后「海底基础信息」组 15 个图层，4 个 Gazetteer 的 defaultOpacity/searchPriority 正确。

## 修复 Gazetteer 图层不显示（N 点/线/面）计数后缀
- 现象：4 个 Gazetteer 图层勾选加载后，图层名后面没有 `(N 点/线/面)` 计数，而其他图层有。
- 根因：`updateLayerCount` 原本放在 `if (!searchIndexMap[checkboxId])` 分支内（loadGeoJSONLayer 第 1155 行）。Gazetteer 带 `searchPriority:true`，启动 2s 后台建索引已设置 `searchIndexMap`，致使勾选加载时该 if 为 false、整段跳过，计数不渲染。
- 修复：把 `updateLayerCount` 抽出为「图层加载完成即无条件执行」（函数内部有空 features 保护），并删除分支内冗余的重复调用。已 `node --check` 通过。
