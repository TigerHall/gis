# 2026-07-17

## iOS 留白区/挖孔区 主题色切换支持

问题：深色模式下 iOS 状态栏/灵动岛/底部 Home 条（安全区留白区）颜色不跟随主题变化。

修复（三处）：
- `index.html`：
  - `apple-mobile-web-app-status-bar-style` 由无效值 `#99cc99` 改为 `black-translucent`（该 meta 仅接受 default/black/black-translucent；配合 `viewport-fit=cover` 让状态栏透明、露出页面背景）。
  - `theme-color` meta 加 `id="themeColorMeta"`，并新增 `media="(prefers-color-scheme: dark)"` 的系统级兜底 meta。
- `assets/main.css`：
  - `:root` 增加 `--c-statusbar: #99cc99`；`[data-theme="dark"]` 增加 `--c-statusbar: #111111` + `color-scheme: dark`。
  - `body` 增加 `background: var(--c-bg)`，使安全区留白区背景随主题变化（之前 body 无背景，深色模式下留白区/挖孔区仍白）。
- `assets/app.js`：
  - 新增 `syncThemeColorMeta()`：读取当前主题 `--c-statusbar` 写入 `theme-color` meta。
  - `darkModeToggle.enable/disable` 均调用 `syncThemeColorMeta()`，切换时同步更新 iOS/Android 状态栏与挖孔区颜色。

注：`test.html` 无深色模式开关，未改动。
